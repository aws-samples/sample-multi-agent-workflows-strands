# Image sources

## Workshop-owned captures

Screenshots `01`–`07` were produced for this workshop from live Lab 6 runs in a
temporary AWS account in `us-west-2` on 2026-10-26:

- `01-telemetry-enabled.jpg` renders the exact managed-telemetry checkpoint output.
- `02-agent-span-tree.jpg` renders the exact real Strands span-tree and redaction-check output.
- `03-gateway-health.jpg` is a cropped CloudWatch GenAI Observability Gateway overview.
- `04-log-correlation.jpg` is a cropped CloudWatch Logs Insights result for the real Gateway call.
- `05-memory-observability.jpg` is a cropped AgentCore Memory metrics view showing real create,
  retrieve, and extraction activity.
- `06-memory-log-lifecycle.jpg` is a cropped CloudWatch Log Analytics result for the real Memory
  extraction and consolidation lifecycle.
- `07-gateway-trace-detail.jpg` is a cropped X-Ray trace detail assembled from the same real
  Gateway invocation to show target execution and Gateway overhead latency.

The captures were cropped to the relevant learning content. The AWS account header,
account ID, full Gateway resource name, log-group name, and authentication details are
not included. No third-party screenshots are used.
